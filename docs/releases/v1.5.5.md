# eShell 1.5.5

Release date: 2026-09-18

## Fixes

### "Check for updates" no longer fails with 403

The Version tab's release lookup called `api.github.com/.../releases/latest`.
That endpoint allows **60 unauthenticated requests per hour per IP**, and a
shared office egress exhausts it on its own. Once the quota was gone every
check failed with:

```
Could not check for updates: the release feed answered 403
```

The command now reads the same `latest.json` the updater plugin installs from.
It is a plain release asset with no rate limit, and it makes the two paths agree
by construction — previously the tab and the in-app installer queried different
sources, so they could report different versions while a release propagated.

Two fields the manifest does not carry are gone:

- **Release notes** are no longer shown in the Version tab. The section hides
  itself when absent; use the release page link for the full notes.
- The installer's reported size is dropped. Nothing displayed it.

Everything else is unchanged: version comparison, the update-available banner,
the in-app install, the manual download button, and the release page link.

## Upgrade Notes

- No configuration or data migration.
- This fix ships in the binary, so it only takes effect once you are running
  1.5.5. A build older than this still queries the rate-limited API.
