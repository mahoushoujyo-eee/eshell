# eShell 1.5.0

Release date: 2026-09-05

## Highlights

### ACP: run external coding agents inside eShell

- The right-side dock now hosts an **Agent Client Protocol** client that drives external coding agents (Codex, Claude Code, OpenCode, Gemini CLI, Qwen Code) as subprocesses over ndjson JSON-RPC, replacing the legacy AI assistant panel.
- Streamed markdown replies, collapsible agent thoughts, tool-call cards with diffs/output/locations, inline permission approval, live plan card, slash-command completion, and a context-usage badge.
- **Model and thinking-effort selection**: the composer's settings button exposes the selectors the agent itself advertises, with the values one hover away.
- Agent sign-in is handled in-panel: a session rejected with `AUTH_REQUIRED` keeps the connection alive and offers one button per advertised auth method, plus manual fallbacks.
- Session history: transcripts persist to `.eshell-data/acp_sessions/` and can be viewed read-only, resumed (native `session/load` when the agent supports it, fresh session otherwise) or deleted.
- Image prompts by paste, gated on the agent's `promptCapabilities.image` and downscaled client-side so oversized images are not silently dropped by the agent.
- Terminal selections can be sent to the agent as context from the terminal's "Add To Agent" action.
- Agents are identified by their brand mark; unrecognized agents get a neutral icon rather than a wrong logo.

### MCP bridge: agents can operate the servers you already have open

- eShell now runs a loopback streamable-HTTP **MCP server** (random port, per-run bearer token) exposing `list_ssh_profiles`, `list_shell_sessions`, `execute_command`, `read_remote_file`, `write_remote_file`, `list_remote_dir` and `get_server_status`.
- The endpoint is injected into ACP agent sessions automatically, so an agent can work on live sessions — scoped to sessions you opened, credentials never exposed, destructive calls still gated by the permission prompt.
- Per-agent opt-out with `"eshellTools": false` in `acp_agents.json`.

### SSH and SFTP

- **Keyboard-interactive (2FA) authentication** with an in-app prompt dialog.
- **Jump host** support via TCP channel forwarding.
- SFTP: rename entries, upload a local file with progress, create files/folders in-app, copy absolute remote paths, sort by name/size/date, toggle hidden files, filter by keyword, right-click menu on tree directories, and auto-refresh after an upload completes.
- SFTP editor saves fall back to a direct overwrite when a server rejects replacing a file through rename, instead of surfacing a generic `SFTP(4)` failure.
- SSH connection attempts can be cancelled while the TCP connect is still pending.
- Status panel refresh interval is configurable (1s/3s/5s/10s) and persisted.

### Web shell reliability

- Dead SSH connections are now detected: the PTY worker pumps libssh2 keepalives, so NAT/firewall idle timeouts surface within ~20-40s instead of freezing silently, and every abnormal PTY exit reports through a new `pty-closed` event.
- Disconnected terminals show a non-interactive overlay with the reason and a Reconnect button, get a red tab dot, swallow keystrokes, and pause status polling.

### Ops Agent and AI configuration

- Image upload in chat, detached attachment persistence, and click-to-view previews for sent images.
- Explicit provider protocol selection (`openai_chat_completions`, `openai_responses`, `anthropic_messages`), dispatched through a shared interface rather than assuming one OpenAI-compatible wire format.
- AI profile UI gains provider icons, provider-aware defaults, and theme-aware chat/approval surfaces.
- AI config import plus a terminal-area command draft panel.

## Upgrade Notes

- **The legacy AI assistant dock is replaced by the ACP panel.** Existing Ops Agent conversations under `.eshell-data/ops_agent_conversations/` are untouched and still reachable; the ACP panel keeps its own transcripts under `.eshell-data/acp_sessions/`.
- `acp_agents.json` is created on first run with a Codex entry. Add Claude Code / OpenCode / Gemini CLI / Qwen Code entries as needed — the agent list reloads whenever the dock opens, no restart required. Optional per-agent keys: `cwd`, `mcpServers`, `eshellTools`.
- Agents need their own credentials. Sign in from the panel, from a terminal (`codex login`), or set the provider key in the agent's `env` in `acp_agents.json`.
- The MCP bridge listens on loopback only, on a random port, with a token regenerated on every run. Set `"eshellTools": false` per agent to keep an agent away from eShell's tools.
- `@xterm/addon-canvas` now has its `@xterm/xterm` peer pinned to the version the app uses (`overrides` in `package.json`). The addon has no stable release supporting xterm 6, and without the override `npm ci` fails outright. It is loaded lazily behind a guard and falls back to the DOM renderer.
- The AI config dialog entry lives in the left toolbar's Config section.

### Known issue

`cargo test --lib` has 4 failing tests in `storage::tests` (`ai_profile_crud_works`, `get_ai_config_prefers_requested_active_profile`, `save_ai_approval_mode_updates_global_setting_only`, `save_ai_config_updates_active_profile`). They read the developer machine's real `.eshell-data/ai_profiles.json` and require a profile with a non-empty API key, so they fail on any checkout without one. Pre-existing, unrelated to this release's changes, and not part of the release build (CI runs `npx tauri build`).
