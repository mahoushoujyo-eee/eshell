# eShell 1.7.1

Release date: 2026-09-30

This release adds SSH local port forwarding — as a panel, and as an API plugins
can drive — plus a Monaco-based file editor with a real save model, a much
faster start, and a fix for the macOS download warning that said the installer
was damaged.

## Port forwarding

- **A Port Forward panel** joins SFTP and Server Status in the bottom dock. It
  lists the active tab's forwards with their listen address, target and state
  (`Active` / `Stopped` / `Failed`), and each row can be stopped or forgotten.
- **Create dialog**: listen address (`Auto` picks a free port from the OS),
  listen port, target host and target port. The target is resolved by the
  **server**, not by this machine, so `localhost` in the dialog means the remote
  host.
- **`-L` style tunneling over the tab's existing SSH connection** (direct-tcpip
  channels) — it reuses the session you already have, including its auth, jump
  host and keepalive. Closing a tab stops its forwards instead of leaving
  listeners accepting into a dead transport.
- **Plugins can drive it too**: `api.forward.create / stop / list / forget` are
  part of the plugin API, and the shared wire fixtures (25 cases) are replayed
  against both the JS facade and the Rust broker so the two lists cannot drift.

## File editor

- **Monaco replaces the textarea editor**, lazy-loaded with language detection,
  and the markdown/Prism stack no longer sits on the startup path.
- **Saving is explicit by default** — Ctrl+S or the Save action — with an
  **Auto sync** switch in Settings for the previous debounced behaviour.
- **Unsaved changes are guarded**: closing or switching away from a dirty buffer
  asks first, and writes are queued so a slow save can never land after a newer
  one.

## Faster start, no white window

- The window is created hidden and shown once the boot splash has painted, so
  launching no longer flashes a blank WebView2 rectangle; a native 8-second
  deadline shows the window if the page never reports in. The splash itself is
  redrawn for both themes and for reduced motion.
- Tailwind's source scanning is scoped to `src/`, `index.html` and `examples/`.
  Automatic detection was crawling `docs/` and the skill folders (653 files) on
  the critical path; scoped it is ~0.7s, dropping only utilities that appeared
  solely in documentation.
- Measured under `tauri dev`: first frame 15.2s → 4.3s, modules loaded
  13.7s → 3.0s. Debug builds also print a merged native + page boot timeline
  (`[boot +Nms]`).

## Smaller changes

- **SFTP**: a go-to-parent-directory button in the path row, disabled at `/`; it
  walks the same route as the tree pane, so the listing, the tree selection and
  the cached children all follow.
- **Dialogs**: the header icon no longer sits on a filled accent chip; the tone
  tints the icon only, and danger/warning keep their meaning through colour and
  icon shape.
- **Settings and rails**: "SSH Servers" is now "Server Management", and the
  redundant one-line descriptions under dialog titles are gone.
- **Security**: `quinn-proto` upgraded to 0.11.14 (CVE-2026-31812).
- **ACP panel**: the session-settings menu is one two-column popup — the option
  list on the left, that option's values on the right, always populated — and it
  opens next to its own button with the current model and thinking effort on the
  button itself. Clicking anywhere outside it now closes it; before, only the
  button could.

## Installing the macOS build

macOS builds are not signed with an Apple Developer ID yet, so a downloaded
`.dmg` is refused by Gatekeeper with a message that says the file is damaged.
It is not damaged — Gatekeeper is blocking an unsigned app, and the wording is
misleading (see the [Releasing Guide](../guides/releasing.md)). Clear the
quarantine attribute before opening, or on the app after installing:

```bash
xattr -dr com.apple.quarantine ~/Downloads/eshell_*_aarch64.dmg
sudo xattr -dr com.apple.quarantine /Applications/eshell.app
```

Right-click → Open and Privacy & Security → "Open Anyway" do **not** clear this
particular message. Existing installs are unaffected: the in-app updater
downloads without a quarantine flag.

## Validation

- `npm run test` — 422 passing (39 files)
- `npm run build` (vite) — passes
- `cargo test --lib` — 249 passing
- The release-prep version bump was checked to leave both suites green before
  tagging, so a build failure on a tag is a CI environment problem, not a
  version mismatch.
- The macOS bundle format was checked against the published 1.7.0 artifact:
  `7z t eshell_1.7.0_aarch64.dmg` reports the image is intact, the bundle has no
  `Contents/_CodeSignature`, and its main binary carries only the linker's
  ad-hoc signature. The new `gatekeeper-check` CI job runs that assessment on a
  macOS runner (with and without a simulated quarantine attribute) so the
  user-visible verdict is observable from CI; it has not yet been run against a
  signed artifact.
