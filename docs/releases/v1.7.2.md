# eShell 1.7.2

Release date: 2026-10-02

This one is all ACP panel. The transcript used to grow a coloured bar down the
left of every tool call, which turned a run of tool calls into a fence; the
composer also could not be enlarged, so editing a long prompt meant scrolling
inside two rows. Both are fixed, and the tool rows were reworked against how
Claude Code actually renders them.

## Tool calls

- **The status rail is gone.** Every tool row carried a 2px coloured
  `border-l-2`; three consecutive rows read as three coloured bars. Status is
  now a 6px dot in a fixed 12px slot, so stacked rows stay aligned and nothing
  runs down the side of the transcript. Shape carries the state as well as
  colour — pending is hollow, running pulses — so it is still readable without
  colour.
- **The `OTHER` chip is gone.** Every MCP tool gets the kind `other` from the
  backend, so the chip read `OTHER` on nearly every row while the tool name
  beside it got less attention. The name is now the row: `mcp__eshell__` and
  the server prefix are stripped, so a row reads `execute_command` instead of
  `mcp__eshell__execute_command`. The full name is still on the row's tooltip.
- **The `已完成` label is gone from the row.** It said the same thing as the dot
  and the colour, three times over, and in Chinese it is a tautology. It stays
  in the accessibility tree, so the row is still announced as
  `execute_command 已完成`.
- **Expanded detail no longer indents.** It sits flush with the row above it.
  Indenting it to line up under the tool name read as a second misalignment
  once the rail was gone.

## Composer

- **The input box can be enlarged.** When the draft no longer fits the two rows,
  a toggle appears in its top-right corner and the box grows to
  `min(52vh, 26rem)`. Escape collapses it, and sending collapses it. Escape is
  stopped from propagating so it does not also close the whole dock.
- **The scrollbar is kept either way.** Expanding only adds room; a draft
  longer than the expanded box still scrolls, and can still be edited there.
- The button appears on a measured overflow rather than a character count,
  because how much wraps depends on the dock width, which can be dragged at
  any time.

## Server status

- **Network traffic is a detail tab** rather than a block permanently stacked
  under the summary bars. It is the least glanceable metric, so it gives up its
  vertical space to CPU and memory and is one click away. Its poll history
  keeps accumulating while the tab is hidden, so opening it shows the graph
  already populated rather than starting empty.

## Smaller changes

- The macOS Gatekeeper check no longer fails on its own cleanup. The `EXIT`
  trap's status was overriding a run that had assessed everything correctly:
  `mount` prints the resolved path (`/private/var/...` for the `/var/...` that
  `mktemp -d` returns), so the `hdiutil detach` was skipped, `rm -rf` failed on
  the still-mounted directory, and the job exited `1`. Teardown now detaches
  unconditionally, disables `set -e` and drops the ERR trap, because the trap's
  exit status is the run's verdict.

## Validation

- `npm run test` — 425 passing (40 files)
- `cargo test --lib` — 249 passing
- The release-prep version bump was checked to leave the JS suite green before
  tagging, so a build failure on a tag is a CI environment problem rather than
  a version mismatch.
- The ACP panel changes were checked against the real component in a browser at
  the default 460px dock width, with the reported transcript replayed through
  it, rather than against a reimplementation: short draft hides the toggle, a
  long draft reveals it, expansion and Escape both toggle the height, and a
  draft longer than the expanded box still scrolls.
- The horizontal-overflow fix was measured on the real generated CSS: at the
  460px dock width, six of ten representative transcript shapes produced a
  horizontal scrollbar before the change and none do after.
