# UI 改造：Termius 风格

分支：`feat/ui-termius-redesign`。范围只包括视觉和布局，不新增功能，不改业务逻辑。

## 调研结论

| 参考 | 可借鉴的做法 |
| --- | --- |
| [Termius](https://termius.com/blog/termius-x) | 宽侧栏换成横向标签，数据和运行中的终端分开，终端占满空间；深蓝灰分层底色，层级靠明暗而不是卡片边框 |
| VS Code | 窄活动栏、底部面板、22px 状态栏；各区域平铺、1px 分隔，全局状态集中在状态栏 |
| Zed | 外框不抢眼、密度高、圆角小；标题栏兼作功能区 |

"AI 生成感"的典型特征（[anti-patterns](https://docs.bswen.com/blog/2026-03-20-ai-generated-ui-anti-patterns/)、[嵌套圆角](https://cloudfour.com/thinks/the-math-behind-nesting-rounded-corners/)）：卡片套卡片、内外不同心的大圆角、装饰性渐变和毛玻璃、到处都有重阴影。改造前的 eShell 在侧栏（22/16/12px 三层圆角卡片）、`body` 三层径向渐变、默认毛玻璃壁纸上都命中了这些特征。

## 布局

```
+------------------------------------------------------------------------------+
| [logo] | (*) prod-box  x | (*) db-01  x | +  |   ...drag...   | AI |  -  []  x |  标题栏 40px
+------+--------------------------------------------------------+--------------+
| rail |  终端                                                  |   AI 面板    |
| 52px +--------------------------------------------------------+              |
|      |  SFTP | 状态 | 命令草稿（32px 面板头）                 |              |
+------+--------------------------------------------------------+--------------+
| (*) root@10.0.0.1:22  |  /var/log  |  运行中  |  问题        |        AI 状态 |  状态栏 24px
+------------------------------------------------------------------------------+
```

- 会话标签在标题栏里；`+` 打开 SSH 配置。标题栏空白处可拖动窗口。
- 活动栏默认 52px 只有图标，展开 220px 带文字。
- 状态栏显示当前会话、当前目录、运行状态、问题、AI 输出状态。

## 设计变量

变量名是插件契约的一部分（外部插件直接用 `bg-panel`、`text-muted` 等类名），只能新增，不能改名。

| 变量 | 用途 | 暗色 | 亮色 |
| --- | --- | --- | --- |
| `bg` | 窗口外框：标题栏、活动栏、状态栏 | `#0e1118` | `#e8ecf2` |
| `surface` | 侧区、面板头、次级区域 | `#141823` | `#f3f5f9` |
| `panel` | 内容区 | `#191e2b` | `#ffffff` |
| `elevated` | 悬停、菜单、弹窗 | `#212839` | `#ffffff` |
| `border` / `border-strong` | 分隔线 / 输入框边框 | `#262d3f` / `#353d54` | `#dde2ea` / `#c5ccd8` |
| `text` / `muted` / `subtle` | 正文 / 次要 / 占位 | `#e3e7f0` / `#8a93a9` / `#6b7389` | `#151a25` / `#5b6478` / `#8a92a5` |
| `accent` / `on-accent` | 强调色 / 强调色底上的文字 | `#3dd68c` / `#062015` | `#0b7a54` / `#ffffff` |
| `accent-soft` | 选中底色 | `#1e3a31` | `#e3f4ec` |
| `warm` | 进度条轨道等中性底色 | `#232a3b` | `#e8ecf2` |
| `info` / `success` / `warning` / `danger` | 状态色 | `#6ea8ff` / `#3dd68c` / `#f0b35a` / `#ff7a7a` | `#2f6fd6` / `#0b7a54` / `#a35f00` / `#c93434` |

强调色取自 logo 光标的绿色。对比度（WCAG）：暗色正文 13.4、次要文字 5.4、强调色 8.9；亮色正文 17.4、次要文字 5.9、强调色 5.4。

强调色底上的文字一律用 `text-on-accent`，不要写 `text-white`：暗色主题的强调色很亮，白字看不清。

圆角：`--radius-sm` 4px（标记、复选框）、`--radius-md` 6px（按钮、输入框、标签）、`--radius-lg` 8px（菜单、列表卡片）、`--radius-xl` 12px（弹窗）。

阴影：只有悬浮层（菜单、弹窗、通知）使用 `--shadow-overlay`，布局内的区域不加阴影。

字体：界面 Geist Variable，终端和代码 JetBrains Mono Variable，中文回退 `Microsoft YaHei UI` / `PingFang SC`。logo 文字保留 Space Grotesk。

## 规则

- 不嵌套卡片；区域之间用 1px 线分隔。
- 内层圆角 = 外层圆角 - 内边距。
- 选中态：`bg-accent-soft` 加左侧 2px 强调条；主按钮才用实心强调色。
- 动效 120–160ms ease-out，不用回弹。
- 终端默认纯色背景，壁纸和毛玻璃是用户可选项。

## 基础组件

`src/components/ui/`：`Dialog`、`Button` / `IconButton`、`fieldClasses`、`SegmentedControl`、`PanelHeader`。新弹窗和面板优先复用这些组件，不再手写遮罩层和按钮样式。
